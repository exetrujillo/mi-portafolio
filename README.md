Soy desarrollador web y cientista social. Me apasiona la intersección entre tecnología y ciencias sociales, creando herramientas que faciliten la investigación y el análisis de datos. Cuando no estoy programando, disfruto estudiar lenguas 🗣️, subir cerros 🚵 y tocar música 🎸.

## Proyectos Destacados

### [Cadáver Exquisito](https://www.cadaverexquisito.cl/)
Plataforma de creación poética colaborativa inspirada en el juego surrealista. Diseñada para la comunidad de la Universidad de Chile, permite construir poemas verso a verso en un entorno lúdico y seguro.

**Stack:** Next.js, TypeScript, PostgreSQL, Tailwind CSS, DaisyUI

### [Datamedios](https://cran.r-project.org/web/packages/datamedios/)
Paquete de R publicado en CRAN para la extracción automatizada y análisis de noticias desde medios de comunicación chilenos. Incluye funciones de limpieza de texto y visualización de datos.

**Stack:** R

### [Raefy](https://github.com/exetrujillo/raefy)
Paquete de R para interactuar con el Diccionario de la Lengua Española (RAE). Permite buscar definiciones, obtener conjugaciones verbales, buscar anagramas, palabra del día y más.

**Stack:** R

### [Plantilla Portfolio Blog](https://github.com/exetrujillo/portafolio-blog-template)
Plantilla moderna para crear sitios de portafolio con blog usando Nuxt 3. Incluye modo claro/oscuro, blog con Markdown y componentes reutilizables. Esta plantilla me sirvió para crear este mismo sitio web.

**Stack:** Nuxt 3, Vue 3, Nuxt Content, Tailwind CSS
